a game that just watch the trajectory of an object fly in space that affected by the planets around, which can see in map, press P to random a new map with random planets position, drag anywhere to shoot the object, the longer the drag the faster the first velocity, but the speed is limited, when it's flying, you can't drag it when it's flying, when touch a planet, the object will stay on the side and you can drag to shoot it again, the circle around the planet display how big the gravitational force of it, after all, the game just for you to see how the trajectory can be, look and see the change of it, if the object get out of the screen, just wait and it will be return after a period of time
Gravitational simulation based on Newton's law (F = GM/r²). Includes features for generating random, non-colliding planets and calculating orbits using vectors.
